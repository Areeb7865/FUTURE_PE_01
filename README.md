# AI Website Copy Generator for Local Coaching Institutes  
**Future Interns – Prompt Engineering Internship (Task 1)**

---

## 📌 Project Overview

This project was developed as part of my **Future Interns Prompt Engineering Internship** under the Prompt Engineering (PE) track.

The goal of this task was to design a **structured prompt system** capable of generating **high-quality, conversion-focused website copy** for a **local coaching institute**, including:
- Homepage content
- Services page content
- Call-to-Action (CTA) section

The project focuses on **prompt engineering, UX writing, and conversion psychology**, rather than frontend development.

---

## 🧩 Problem Statement

Many local coaching institutes struggle to create professional, trustworthy, and conversion-oriented website copy due to:
- Limited access to professional copywriters
- High costs of content creation
- Lack of clarity in communicating value to parents and students

AI tools can help solve this problem **only when guided by well-structured prompts** that consider:
- Audience psychology
- User intent
- Website structure
- Conversion goals

---

## 💡 Solution Approach

To address this problem, the project follows a **modular prompt engineering approach**, where each major website section is handled by a **separate, specialized prompt**.

Instead of using one large generic prompt, the website copy was generated using **section-wise prompts**, each designed with:
- A clear role definition
- Target audience segmentation
- Specific UX and conversion goals
- Controlled tone and output format

This approach improves:
- Output quality
- Reusability
- Maintainability
- Clarity during evaluation

---

## 🧠 Prompt Engineering Strategy

The prompt system was designed with the following principles:

- **Role-Based Prompting**  
  Each prompt assigns a clear professional role (UX Content Strategist, CRO Specialist) to guide the AI’s thinking.

- **Audience Segmentation**  
  Primary focus on parents (decision-makers) and secondary focus on students (influencers).

- **Modular Design**  
  Separate prompts for Homepage, Services Page, and CTA ensure focused and consistent outputs.

- **Conversion-Aware Writing**  
  Homepage focuses on trust and value, Services page on clarity and differentiation, and CTA on low-risk engagement.

- **Strict Output Constraints**  
  Content-only generation using Markdown (no HTML/CSS or UI code).

## 📚 Key Learnings

- Well-defined prompts significantly improve AI output quality
- Different website sections require different prompting strategies
- Parents and students respond to different emotional cues
- Modular prompt systems are more reusable than single large prompts
- Conversion-focused CTA writing is about reassurance, not pressure
